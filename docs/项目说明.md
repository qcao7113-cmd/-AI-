# 项目说明

## 一、系统定位

「药膳智养」是一套面向**慢性病人群的中医食疗管理平台**（管理端），用于健康管理机构、中医馆、社区康养中心等场景：

- 管理平台用户及其**中医体质辨识**结果与**慢性病标签**
- 维护**药食同源食材库**（四气五味、归经、功效、库存）
- 维护**辨证施膳药膳食谱**，并自动匹配适用体质与慢病
- 追踪用户**每日药膳用餐记录**与满意度
- 记录**体检指标**（BMI、血压、血糖、尿酸）并自动预警
- 制定**五大慢病的食疗方案**（原则、推荐、忌口）
- 通过**角色权限**控制不同岗位的可见与可操作范围
- 通过**审计日志**追溯平台关键操作

## 二、功能模块

| 模块 | 路径 | 主要能力 |
| --- | --- | --- |
| 数据概览 | `/dashboard` | 4 项 KPI、近两周趋势折线图、慢病分布环形图、体质柱状图、热门食谱、库存预警、最新用餐 |
| 用户管理 | `/users` | 分页表格、关键字搜索、角色/状态筛选、新增/编辑抽屉、删除确认、CSV 导出 |
| 角色权限 | `/roles` | 三张角色卡片、按分组勾选权限、保存后即时生效（含当前登录角色） |
| 食材库 | `/ingredients` | 四气五味标签体系、归经与功效、库存状态预警、增删改、CSV 导出 |
| 药膳食谱 | `/recipes` | 卡片视图、按类型/状态筛选、详情抽屉（食材配比+适用人群）、编辑表单 |
| 用餐记录 | `/meals` | 餐次筛选、满意度星级、热量统计、CSV 导出 |
| 健康档案 | `/health` | BMI 自动计算与分级、三高指标异常高亮、录入体检数据 |
| 慢病方案 | `/chronic` | 五大慢病食疗方案卡片、食疗原则/推荐/忌口在线编辑 |
| 审计日志 | `/audit` | 操作类型筛选、IP 与结果记录、CSV 导出 |
| 系统设置 | `/settings` | 主题、密度、分页、自动刷新、默认落地页；账号信息；重置演示数据 |

## 三、权限矩阵

| 权限码 | 说明 | 超级管理员 | 健康管理师 | 普通用户 |
| --- | --- | :-: | :-: | :-: |
| `user:view` | 查看用户 | ✅ | ✅ | |
| `user:manage` | 管理用户 | ✅ | | |
| `ingredient:view` | 查看食材 | ✅ | ✅ | |
| `ingredient:manage` | 维护食材 | ✅ | ✅ | |
| `recipe:view` | 查看食谱 | ✅ | ✅ | ✅ |
| `recipe:manage` | 编辑食谱 | ✅ | ✅ | |
| `meal:view` | 查看用餐记录 | ✅ | ✅ | ✅ |
| `health:view` | 查看健康档案 | ✅ | ✅ | ✅ |
| `health:manage` | 管理健康档案 | ✅ | ✅ | |
| `plan:manage` | 慢病方案 | ✅ | ✅ | |
| `role:manage` | 角色与设置 | ✅ | | |

权限在三个层面生效：

1. **菜单级** —— 无权限的菜单项不渲染（`AppLayout` 中的 `visibleSections`）
2. **路由级** —— 直接输入 URL 会被 `RequirePermission` 拦截，显示「无访问权限」页
3. **按钮级** —— 新增/编辑/删除按钮通过 `can()` + `Can` 组件控制

## 四、数据模型

- **User**：姓名、账号、手机、邮箱、性别、年龄、体质、慢病标签、角色、状态
- **Ingredient**：名称、分类、四气、五味、归经、功效、热量、单位、库存、状态
- **Recipe**：名称、类型、适用体质、适用慢病、食材配比、功效、热量、时长、状态、浏览/收藏
- **MealRecord**：用户、食谱、餐次、份数、热量、评分、备注、时间
- **HealthProfile**：身高、体重、血糖、尿酸、收缩压、舒张压、更新时间
- **ChronicPlan**：慢病类型、概述、食疗原则、推荐食材、忌口、在管人数
- **AuditEntry**：操作人、类型、对象、详情、IP、结果、时间

完整定义见 `src/types/index.ts`。
